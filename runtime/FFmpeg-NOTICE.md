# Bundled FFmpeg tools

SyncCut bundles FFmpeg and FFprobe to simplify local runtime setup and media export.
Release builds use the Windows x64 GPL build from BtbN/FFmpeg-Builds, verified against the release SHA-256 checksum before packaging.

FFmpeg is licensed under the GNU General Public License for this build. License and corresponding source/build instructions are available from:

- https://ffmpeg.org/legal.html
- https://github.com/BtbN/FFmpeg-Builds
- https://github.com/FFmpeg/FFmpeg

The exact FFmpeg build tag is included as `ffmpeg-release.txt` in the GitHub release assets.
