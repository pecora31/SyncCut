# UI Guidelines & User Preferences

- **ENGLISH PRIMARY LANGUAGE ONLY**: The UI must strictly default to English across all labels, buttons, dropdowns, inputs, and messages. Never change or mix languages without explicit instructions.
- **NO WORDY ANNOTATIONS**: Do NOT write explanatory annotations or parentheticals inside option items (e.g. use `.mp4` instead of `.mp4 (H.264 - ...)`, use `1080p` instead of `Full HD (1080p)`). Keep options concise and direct.
- **NO ICONS**: Do NOT add any icons, emoji icons, or icon packages (e.g. lucide-react, SVG icons, emojis) anywhere in the user interface unless the user EXPLICITLY asks for them.
- **NEUTRAL TEXT COLORS ONLY**: Never use colored text (green, yellow, blue, cyan, orange, red, purple) for labels, headings, or status tags unless requested. Use neutral grayscale shades:
  - Heading & Primary: `#ffffff`, `#e6e6e6`
  - Body & Secondary: `#cccccc`, `#a0a0a0`
  - Muted: `#757575`, `#666666`
- Keep interface minimalist, clean, neutral, and professional.
