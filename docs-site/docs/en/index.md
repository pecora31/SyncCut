# SyncCut user guide

SyncCut is a local post-production assistant. It aligns an English voiceover with a script, indexes footage, finds relevant shots, and builds an editable timeline.

The Vietnamese guide is the primary reference. Use this English companion when your team prefers English UI terms.

## Recommended path

1. [Setup and first workflow](setup-and-workflow.md)
2. Import footage, voiceover, and script.
3. Review the transcript and scene candidates.
4. Rebuild the timeline and export an XML for Premiere Pro.
5. [Troubleshooting](troubleshooting.md)

SyncCut creates suggestions. Always review transcript boundaries, selected shots, gaps, and the exported timeline before delivery.

See the full Vietnamese documentation at [pecora31.github.io/SyncCut](https://pecora31.github.io/SyncCut/vi/).
