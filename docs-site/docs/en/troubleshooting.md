# Troubleshooting

**Runtime is unavailable:** open Settings, select the installed runtime, and run the customer validation command. Restart SyncCut after changing the runtime.

**CUDA or VRAM errors:** switch from Quality to Fast, close GPU-heavy applications, reduce parallel workers, and retry the failed job.

**Transcript is inaccurate:** check the voiceover file, language, noise level, and script encoding. Correct key lines in the review panel before rebuilding.

**Scene candidates are weak:** improve the visual brief, inspect evidence frames, and lower the acceptance threshold only when you are prepared to review more false positives.

**Premiere shows offline media:** relink to the original footage folder. Do not move or rename source files between export and relink.

For the complete decision tree, use the [Vietnamese troubleshooting guide](https://pecora31.github.io/SyncCut/vi/troubleshooting/).
