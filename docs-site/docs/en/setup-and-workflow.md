# Setup and workflow

## Before you start

Use the customer runtime package and run the setup script once. On a machine with 32 GB RAM and an RTX 3060 12 GB, start with the **Fast** profile when Premiere Pro, Chrome, or a game is running. Use **Quality** for a dedicated processing session.

Create one project folder per job. Keep the original footage and voiceover in stable locations; moving them later creates offline media in the export.

## Process

1. Open or create a project.
2. Import the voiceover and script, then verify the language is English.
3. Import all footage. Assign a role to each source when useful.
4. Run transcription and alignment. Inspect low-confidence words and timing issues.
5. Run scene analysis. Compare each candidate with the visual brief and evidence frame.
6. Review the timeline. Fix gaps, overlaps, pacing, and unsuitable shots.
7. Lock the approved timeline and export the edit package/XML.
8. Open the XML in Premiere Pro and relink media if required.

Pause jobs when you need GPU capacity for another application. Resume from the Jobs view after the competing workload ends.

## Review checklist

- Voiceover and script convey the same meaning.
- Low-confidence transcript spans have been listened to.
- Each important scene has an acceptable evidence frame.
- No timeline gap or overlap is accidental.
- Source paths remain available to Premiere Pro.
- Exported video and audio settings match the delivery brief.
